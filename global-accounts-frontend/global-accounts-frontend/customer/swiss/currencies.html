Currencies

Five supported currencies, one account

Each currency is a separate account with its own balance, history, deposit records and status. Activation is self-service, new accounts always start at zero, and nothing is converted automatically. A sixth currency is listed in its unavailable state so the behaviour is visible.

The set

Six listed, five activatable

NGN — Nigerian Naira

Default for Nigeria. Deposits by debit card, payment gateway or bank transfer — credit card is not supported for NGN.

Active

USD — US Dollar

Default where a country has no national currency in the supported set. All four deposit methods are available.

Active

GBP — British Pound

Default for the United Kingdom. All four deposit methods are available.

Active

EUR — Euro

Default for eurozone countries — Germany, France, Italy, Spain, the Netherlands, Belgium, Ireland, Austria, Portugal and Finland.

Active

CHF — Swiss Franc

Default for Switzerland. All four deposit methods are available.

Active

JPY — Japanese Yen

Temporarily unavailable for activation while we extend the demo. The state is shown live wherever currencies appear, and activation is disabled until it returns.

Unavailable
