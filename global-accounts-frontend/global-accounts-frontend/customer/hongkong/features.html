Core capabilities

Deposits, simulated end-to-end

Choose a currency, an amount and a method, review the fee, then pay through the mock gateway. The simulator can return any of five outcomes, so every resulting state is demonstrable — including what a duplicate reference looks like when a payment is attempted twice.

Only successful payments credit a balance. Pending, failed, cancelled and duplicate attempts never do — and the history shows exactly which happened.
