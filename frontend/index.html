Designed around account control

Security and transparency built into the experience

Verification, device-level session control and a transparent audit trail — security features you can actually see and operate, not fine print.

Administrative access is logged and always visible. Administrators can never withdraw, transfer or edit balances — the restriction is enforced in the service layer, not by hiding buttons.

  • 📱
    Session control

    See every active device and revoke anything you don't recognise, instantly.

  • ⚠
    Suspicious-activity alerts

    Unusual patterns are flagged in your security history.

  • ❄
    Administrative safeguards

    Support access is role-based, audited and financially read-only by design.
